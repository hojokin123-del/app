# KPI経営管理フォーマット

自走型組織を構築するための、KPI・進捗・資金繰りを一元管理するExcelフォーマットです。
毎日の動きと成果、仕組化の状況を記録し、売上・利益目標の達成率を可視化して、資金繰りまでつなげます。

ファイル: [`KPI経営管理フォーマット.xlsx`](./KPI経営管理フォーマット.xlsx)

## シート構成

| シート | 用途 | 更新頻度 |
|---|---|---|
| **使い方** | 目的・運用サイクル・色の凡例 | 最初に一読 |
| **ダッシュボード** | 売上/利益の達成率・資金残高・今後の方向性を一覧 | 毎月 |
| **KPI目標実績** | 売上・利益・活動KPIの年間目標と月次実績→達成率を自動計算 | 毎月 |
| **日次活動記録** | 毎日の活動・成果・重要数値・課題・翌日アクション | 毎日 |
| **週次進捗レビュー** | 週ごとの目標対比・学び・改善・方向性（達成率は自動） | 毎週 |
| **資金繰り表** | 月次の入出金・営業収支・月末資金残高（自動計算・翌月へ繰越） | 毎月 |
| **仕組化チェック** | 標準化・マニュアル化・権限委譲の進捗（自走化） | 四半期 |

## 使い方のポイント

- **黄色のセル**が入力欄です。**緑色のセル**は自動計算なので編集しないでください。
- 数式（達成率・合計・資金残高・進捗率）はすべて自動計算されます。数値を入れ替えると即座に再計算されます。
- 各シートには記入例が1行入っています。自社の数値に置き換えてお使いください。
- 資金繰り表は、当月の「翌月繰越」が翌月の「前月繰越」へ自動的に引き継がれます。「最低月末残高」がマイナスになる月は資金ショートの恐れがあります（ダッシュボードで確認）。

## 運用サイクル

- 毎日: 日次活動記録
- 毎週: 週次進捗レビュー（15〜30分のふりかえり）
- 毎月: KPI実績入力 → ダッシュボード確認 → 資金繰り表更新
- 四半期: 仕組化チェックで自走化の打ち手を決定

## アプリ版（ブラウザで入力・自動計算）

このExcelフォーマットと同じ内容を、本アプリでブラウザ上で入力・自動計算できます
（`npm run dev` で起動 → 左サイドバーの各メニュー）。

- 経営ダッシュボード（`/`）… 達成率・資金残高・仕組化進捗・資金ショート警告
- KPI目標・実績（`/targets`）… 月次入力→累計・達成率を自動計算、CSV出力
- 日次活動記録（`/daily`）／週次進捗レビュー（`/weekly`）
- 資金繰り表（`/cashflow`）… 翌月繰越を自動引継ぎ、CSV出力
- 仕組化チェック（`/systemize`）… 進捗率を自動集計

入力データはブラウザのlocalStorageに自動保存されます。実装は `src/kpi/`・`src/pages/kpi/`・
`src/store/useKpiStore.ts` を参照してください。
