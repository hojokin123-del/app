# 運用ルール（ファイル命名・保存・セキュリティ）

## 1. ファイル・フォルダ命名規則

### 顧客フォルダ（Google Drive）
```
顧客/
  <会社名>/
    01_契約・請求/
    02_助成金・補助金/
      <制度名>_<年度>/        例: 業務改善助成金_2026/
    03_ヒアリング・提案/
    04_納品物/
```

### ファイル名
```
<日付YYYYMMDD>_<顧客名>_<種別>_<内容>.<拡張子>
例: 20260704_合同会社YOLO_提案_助成金タイムスケジュール.csv
例: 20260710_UNITENS_申請_持続化補助金様式3.xlsx
```
- 種別は: 提案 / ヒアリング / 申請 / 実績報告 / 請求 / 契約 / 議事録
- 「コピー」「最新」「final2」を名前に入れない。版が変わったら日付を変える

## 2. セキュリティルール（必読）

### ⚠ 今すぐ対応すべきこと
**スプレッドシート「助成金補助金2020プロジェクト」の「PASS」シートに、ログインID・パスワードが平文で保存されています。**
このシートは共有されており、閲覧権限のある全員がパスワードを見られる状態です。
1. 該当サービスのパスワードを変更する
2. シートからパスワード行を削除する（削除しても閲覧履歴・版履歴に残るため、パスワード変更が先）
3. 以後、パスワードはパスワードマネージャー（Google パスワードマネージャー、1Password 等）にのみ保存する

### 恒常ルール
- パスワード・APIキー・マイナンバー・口座情報をスプレッドシート/ドキュメント/チャットに書かない
- 顧客の決算書・賃金台帳は該当顧客フォルダの外に置かない（営業リストと混ぜない）
- 共有リンクは「リンクを知っている全員」を避け、相手を指定して共有する
- AI（Claude含む）に渡す資料から、作業に不要な個人情報（従業員個人名・給与額）はできるだけ落とす

## 3. AI利用の運用ルール

- AIの出力は常に**下書き**。送信・提出・投稿・請求書発行は人間が行う
- 金額・法令要件は公募要領・支給要領の**原文**で最終確認する（AIの記憶を信用しない）
- 破壊的操作（ファイル削除・上書き・一括変更）は事前に対象を確認してから
- 採択された申請書は匿名化して `business-os/knowledge/` に貯める（次回の精度が上がる）

## 4. 週次・月次の定例運用

- 毎週月曜: 全案件のタイムスケジュール表を見て、今週締切のタスクを洗い出す（→ 将来は案件ダッシュボードに置き換え）
- 毎月第1営業日: 月別回収シートをCSVで書き出し、Claudeに「未請求・未入金・紹介料未計算」をチェックさせる
- 毎月末: 新規顧客のフォルダ・台帳が命名規則どおりかを確認
