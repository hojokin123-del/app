# コピペ用 定型プロンプト集

Claude（claude.ai / Claude Code どちらでも）にそのまま貼って使う。`＜＞` の部分だけ書き換える。

---

## 1. 公募要領の新旧差分要約

```
あなたは補助金の公募要領を精読する専門家です。
添付の2つの公募要領（＜前回：13次＞と＜今回：14次＞）を比較し、以下を出してください。

1. 主要な違いの比較表（項目 / 前回 / 今回）
2. 実務に影響する変更ポイントの解説（申請期間、補助上限、補助率、対象経費、要件、返還規定）
3. 顧客に案内すべき注意点（GビズID取得期間なども含む）

ルール:
- 原文に書いていないことは書かない。該当ページ・条項番号を併記する
- 変更なしの項目は省略してよい
```

## 2. 月別回収チェック

```
添付は当社の回収管理CSVです。列: 申請月, アライアンス, クライアント, 適用, 金額, ステータス, 振込先。
以下を表で出してください。

1. ステータスが「未請求」のもの（金額合計つき）
2. 「請求済み」だが入金確認列が空のもの
3. 金額が空欄・0円で放置されているもの
4. 紹介手数料の計算が必要そうなもの（アライアンス欄あり・手数料欄なし）

最後に「今月やるべき回収アクション」を優先順に3つ。
数字は原文のまま使い、推測で埋めないでください。
```

## 3. 商談メモ → 議事録・次アクション

```
以下は商談の走り書きメモ（または文字起こし）です。これを:
1. 議事録（日時/参加者/決定事項/保留事項）
2. 次アクション表（誰が/何を/いつまでに）
3. 提案すべき助成金・商材の候補（あれば）
に整理してください。メモにない事実は創作しないでください。

--- メモ ---
＜ここに貼る＞
```

## 4. ヒアリング逆質問リスト

```
＜制度名＞の申請書を作る前提で、以下の顧客情報を読み、
「申請書作成に足りない情報」を顧客に送れる質問リスト（箇条書き、敬語）にしてください。
経営者がスマホで答えられる粒度に分解してください。

--- 顧客情報 ---
＜hojokin-navi.html のヒアリングテキストを貼る＞
```

## 5. 週次公募ウォッチ（手動実行版）

```
次の制度について、今日時点の最新公募状況（公募回、申請受付期間、締切、変更点）をWeb検索で調べ、
出典URL付きの一覧表にしてください。確認できなかったものは「確認できず」と書いてください。

対象: 小規模事業者持続化補助金 / 業務改善助成金 / 中小企業省力化補助金 /
事業承継・M&A補助金 / IT導入補助金 / 人材開発支援助成金 / キャリアアップ助成金 /
働き方改革推進支援助成金 / 人材確保等支援助成金

最後に「今週、既存顧客に提案できそうな動き」を3行で。
```
