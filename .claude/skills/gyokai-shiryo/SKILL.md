# 業界別 提案資料ジェネレーター

商材と助成金を組み合わせた、印刷1枚（＝1業種1ページ）の営業資料を作る。

## 絶対ルール
- 助成金の金額・補助率・上限・加算は**記憶で書かない**。WebSearchで最新を確認し出典を残す。確認できなければ概算＋【要確認】と明記。
- 「必ずもらえる／受給保証」表現は禁止。「対象になり得る」「目安」に統一。
- 導入・賃上げは**交付決定“後”に実施**が原則である旨を必ず入れる（事前着手は対象外）。
- 出力は営業下書き。金額・要件は提案前に人間が公募要領で最終確認する前提。

## 入力
- 商材名と1行説明、標準的な導入費用
- 使う助成金（コース名）
- 対象業界リスト
- 賃上げなど加算の前提（例: 対象1名7%賃上げ）

## 構成（業界ごとに1シート）
1. eyebrow（〇〇業向け）＋ 刺さる見出し（現場の痛みを疑問形で）
2. 現場の困りごと 3つ（！マーク、具体的な業務描写で。抽象語NG）
3. 商材が変えること 3つ（✓、機能ではなく“何が無くなる/増える”で）
4. 効果メトリクス 3つ（数字＋一言）
5. 資金計画ミニ表（導入費 / 助成金目安 / 実質負担 / 賃上げ要件）
6. 商談での一言（そのまま言えるトークスクリプト1文）
7. 必要なら業界特有の注意書き（例: 葬儀は「AIは一次受付＋即エスカレーション」に限定）

冒頭に共通の「資金スキーム」バンド（制度の仕組み・補助率・加算・⚠要確認）を置く。

## 出力形式
- 単一HTMLファイル（`tools/<商材>-eigyo.html`）。オフライン動作・印刷CSS（1業種=1ページ）・ダーク/ライト両対応。
- 業界データは script 内の配列で持ち、追加業種は配列に足すだけで増える構造にする。
- 既存の `tools/smartcall-eigyo.html` をテンプレートとして複製・改変してよい。

## 完成サンプル
`tools/smartcall-eigyo.html`（歯科医院・サロン・整体接骨院・飲食・葬儀の5業種、働き方改革推進支援助成金）。
