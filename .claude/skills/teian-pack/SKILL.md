# 提案書・DM・商談台本生成 Skill

## 絶対ルール
- **出力は下書き。メール送信・LINE送信・投稿は絶対にしない。**
- 助成金の金額・要件は概算として書き、「※最新の公募要領に基づく確認が必要です」を必ず入れる。
- 受給を保証する表現（「必ずもらえる」「100%受給」）は使わない。「対象となる可能性があります」に統一。
- 顧客の実名・具体的な金額を含む出力の冒頭に `【送信前に宛名・金額・敬称を確認】` を付ける。

## 入力
最低限: 会社名（または「新規リード」）、業種、従業員数。
あれば: 課題（採用/賃上げ/研修/設備投資）、既存の関係性（既存客/紹介/新規）、提案したい商材（助成金/オタスケAI各種/研修）。
不足していても推測で下書きし、推測箇所を `（※要調整: 〇〇）` で示す。

## 文体・トーン（既存テンプレに合わせる）
- 丁寧なビジネス敬語。売り込み色を抑え「整理のお手伝い」「ご案内」の文脈で書く
- 1通は短く（スマホで2スクロール以内）。結論 → 理由 → 次アクション（返信 or 日程）の順
- 新規向けは「まず案内の許可をもらう」2段構え（許可依頼文 → ポジティブ返信後の本文）

## 出力メニュー（依頼に応じて選択）

### A. DM / 案内文
既存客向けと新規向けの2パターン。新規向けは許可依頼文＋フォロー文のセット。

### B. 提案書（1枚もの構成）
1. 貴社の状況（ヒアリングの要約）
2. 活用できる可能性のある制度・サービス（表: 制度名 / 概要 / 概算受給額 / 弊社手数料）
3. スケジュール（hojokin-navi.html のタイムスケジュールを貼る欄）
4. 次のステップ

### C. 商談台本（30〜45分）
STEP1 アイスブレイク・目的共有（5分）→ STEP2 現状確認（10分）→ STEP3 課題深掘り（10分、課題別質問リスト付き）→ STEP4 ソリューション提示（10分、決めつけず選択肢で）→ STEP5 クロージング（5分、次アクションをその場で確定）。
ポイント: 「営業」ではなく「整理の手伝い」の立ち位置。社長自身が課題を言語化する瞬間を作る質問を入れる。

### D. 料金シミュレーション文面
研修費用・助成金額・手数料・実質負担を表で。計算式を明示し、検算できる形にする。

## 出力形式
Markdown。コピペ用の本文はコードブロックに入れる（コピーしやすくするため）。
最後に「送信前チェック: 宛名 / 金額 / 敬称 / 添付 / 誤送信先」の5点を必ず付ける。
