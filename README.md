# 代理店フィー管理システム

販売代理店制度における、毎月月末の代理店フィー（手数料）計算と支払明細書作成を自動化する Web アプリです。React + TypeScript + Vite で構築しています。

## 主な機能

### 1. 代理店マスター（`/agencies`）
- 一次代理店・二次代理店の登録／編集／削除
- 代理店ごとの**手数料率（％）**を個別に登録
- 二次代理店には所属する一次代理店を紐付け
- 振込先口座・担当者情報を管理

### 2. 売上データ（`/sales`）
- 研修売上の登録・一覧・月次フィルタ
- 「研修に関する売上」フラグでフィー計算対象を管理

### 3. スプレッドシート連携（`/sales/import`）
- 売上のベースとなるスプレッドシート「2025.4～」の入金台帳
  （`ランク／代理店／顧客名／種類／日付／入金／…／残高`）をコピー＆ペーストで取り込み
- **「代理店」列に会社名が入っており、かつ「入金」がある行**を自動抽出し、
  **入金日の月**をキーに代理店マスターと突合して売上へ転記
- 経費行（入金なし・AMEX等）や代理店が空欄の行（例：アサユサイト）は自動的に対象外
- カンマ区切り／タブ区切り（スプレッドシートから直接コピー）に対応

### 4. フィー計算（`/fees`）
- 対象月を選ぶと**オーバーライド型**で代理店別フィーを自動計算
- 代理店ごとの明細（直販・販売・オーバーライド）を展開表示
- ワンクリックで支払明細書を作成

### 5. 支払明細書（`/statements`）
- 代理店別・月別の支払明細書を一覧管理
- 明細書は手数料小計＋消費税−振込手数料＝差引支払額を自動計算
- 印刷／PDF 出力、確定処理に対応

### 6. 設定（`/settings`）
- 自社名・消費税率・標準振込手数料・支払日
- 研修判定キーワードの追加・削除

## フィー計算方式（オーバーライド型）

- 二次代理店が販売した研修費用に対し、**二次代理店は自社率**を計上
- 同じ研修費用に対し、所属する**一次代理店は一次率**をオーバーライドとして計上
- 一次代理店の直販は**一次率のみ**を計上

例）研修費用 3,000,000 円・一次率 55%・二次率 45% の場合
→ 一次代理店：1,650,000 円（オーバーライド）／二次代理店：1,350,000 円（販売フィー）

## 初期データについて

初期データは Google スプレッドシート「石川決済（西河マネジメントセンター）」の
シート「2025.4～」の入金台帳から、「代理店」列に会社名が入っておりかつ「入金」がある行を、
入金日の月をキーに転記して作成しています（2025年4月分：コミクス／ADH／ｹｰﾌﾟﾗﾝﾆﾝｸﾞ／MMH／Leap）。

なお、このシートには代理店ごとの手数料率(%)の記載が無いため、代理店マスターの料率は暫定値です。
実際の契約率は「代理店マスター」で登録・調整してください。

本アプリはブラウザ上のインメモリ状態で動作するデモ実装です（リロードで初期状態に戻ります）。

## 開発

```bash
npm install
npm run dev     # 開発サーバ
npm run build   # 型チェック + 本番ビルド
npm run lint    # ESLint
```
